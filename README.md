# REDACTR

REDACTR is a desktop redaction tool for video, images, and audio.

## Download

Download the latest REDACTR installer from the Releases section.

## Current Version

REDACTR v2.1

## Installation

1. Download the REDACTR installer.
2. Run the installer.
3. Follow the installation prompts.
4. Launch REDACTR.

REDACTR runs locally on the user's computer.
